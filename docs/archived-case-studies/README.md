# Archived case studies

These case studies are preserved outside Hugo's content directory and are not published. Colorado Sauce Company, TGB Flooring, and Nano Bella are the current public portfolio. TGB Flooring and its journal excerpt have been restored.

To restore a case study, move its Markdown file back to `content/work/`, remove its old-path alias from `content/work/_index.md`, and review its homepage, founder, service, and journal references. The original case-study files are preserved unchanged. Supporting images remain in the repository.

Old case-study URLs redirect to the Work index. Existing client testimonials are independent of the case-study selection.
